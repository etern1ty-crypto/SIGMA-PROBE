# Технический аудит исходного SIGMA-PROBE

Дата ревизии: 2026-09-08. Источник: пользовательский `SIGMA-PROBE-main.zip`, SHA-256 `c1d42366af673cf2068b59f21f2d648a3ff066e61debca9c5654691940f441ad`.

**Все номера строк ниже относятся к исходному архиву, не к переработанной версии.** Исправления — целевой рефакторинг 3.0.0rc1 с намеренной сменой контрактов; совместимость описана в [MIGRATION.md](MIGRATION.md).

## Метод и ограничения

Прочитаны все исходные модули, конфигурация, упаковка, документация и тесты. Проверен синтаксис исходных Python-файлов. Критические разрывы воспроизведены отдельным скриптом; результаты лежат в `evidence/original-reproductions.json`. При изоляции парсера обходился только eager-import `pipeline/__init__.py`, чтобы отсутствие научных библиотек не скрыло дефект контрактов.

Исходный pytest-suite **не запускался успешно**: pytest отсутствует, установка инструментов из доступного индекса не удалась. Это ограничение среды, не самостоятельный дефект проекта. Нельзя выдавать выборочные воспроизведения за полный прогон старых тестов. Для нового продукта используется исполняемый стандартной библиотекой `unittest` suite.

Статический обзор не доказывает отсутствие всех уязвимостей. Нет реальных клиентских логов, размеченного корпуса, сетевого CVE-аудита или запущенного Docker daemon. Конкретные границы готовности — в [VALIDATION.md](VALIDATION.md).

## Заглушки, секреты, гонки

- Найденные `pass` в `base.py:21,33,53` — тела **абстрактных методов**, не три независимых пропущенных бизнес-функции. Реальная опасная заглушка — `BaseDetector.detect(): return {}` в `detectors.py:61–67`.
- Другие недоделки: полностью skipped E2E, отсутствующие fixture/sample log, фиктивные URL фидов, неиспользуемые настройки, неработающие ветки recommendation/MITRE, отчёты без сохранения.
- Рабочих токенов/API-ключей в архиве не обнаружено. `token=...` встречается в синтетических URL тестов; это не доказательство утечки действующего секрета.
- Доказанной гонки потоков в исходнике нет. Есть состояние между запусками и лишняя сложность multiprocessing, а не основание выдумывать race-condition.
- Версии в pyproject заданы диапазонами, lock отсутствует; конкретные установленные версии исходного проекта неизвестны. Нельзя приписать ему определённые CVE без resolution и актуального advisory scan.

## Порядок реализации

1. Новые строгие модели/конфиг и реальные парсеры; восстановить happy path.
2. Убрать ложную семантику FFT/ML, корректно агрегировать сигналы и корреляцию.
3. Встроить local IoC, объяснимый scoring, MITRE-контекст и рекомендации.
4. Безопасная сериализация, атомарные отчёты, privacy controls, полноценный CLI.
5. Регрессионные/E2E/security тесты, offline wheel/zipapp, контейнерные файлы.
6. README/docs, журнал проверок, полный source listing и release manifest.

Оригинальные файлы сохранены в исходном пользовательском ZIP. В итоговом архиве также есть полный patch относительно него; скрытого удаления функциональности нет — намеренные изменения продукта перечислены в MIGRATION.md.
